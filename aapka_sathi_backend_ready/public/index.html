Waiting for messages…

Messages are not stored by this app. They disappear when you leave, refresh, or disconnect.

Privacy notes
• No account, phone number, or email is required.
• AES-GCM encryption happens in your browser; the key is not sent to the chat server.
• The server keeps room membership in memory and relays ciphertext only; it does not save messages.
• The hosting provider may still see connection metadata such as IP address. This starter has not had an independent security audit; do not use it for highly sensitive information.
